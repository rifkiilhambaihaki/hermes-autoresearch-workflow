# Templates

Use these files to keep project artifacts consistent:

- [Project README](README-project-template.md) — project purpose, structure, and usage notes.
- [Dataset inspection](dataset-inspection-template.md) — dataset inventory and readiness findings.
- [Baseline analysis](baseline-analysis-template.md) — baseline evidence and interpretation.
- [Transfer-learning analysis](transfer-learning-analysis-template.md) — comparison and iteration decision.
- [Final audit](final-audit-template.md) — final evidence review.
- [Final report](final-report-template.md) — project summary and limitations.
- [Artifact index](artifact-index-template.md) — links to artifacts that actually exist.

Replace placeholders, preserve provenance, and never invent results or links.
