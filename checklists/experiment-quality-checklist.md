# Experiment Quality Checklist

- [ ] Train/validation/test split konsisten.
- [ ] Split bebas data leakage.
- [ ] Semua kelas muncul di setiap split.
- [ ] Validation digunakan untuk iterasi/model selection; held-out test disimpan untuk evaluasi final.
- [ ] Metrik lengkap tersedia.
- [ ] Confusion matrix tersedia.
- [ ] Classification report tersedia.
- [ ] Training curve tersedia.
- [ ] Model tersimpan.
- [ ] Experiment log tersimpan.
- [ ] Parameter eksperimen tercatat.
- [ ] Random seed, dependency/runtime version, dan environment tercatat.
- [ ] Notebook dapat dijalankan ulang di Colab.
