# Checklists

Review these checklists at the matching workflow gate:

- [Dataset readiness](dataset-readiness-checklist.md) — verify inputs before notebook generation or training.
- [Experiment quality](experiment-quality-checklist.md) — check whether an experiment is reproducible and interpretable.
- [Keep/discard decision](keep-discard-decision-checklist.md) — document an evidence-based iteration decision.
- [Final audit](final-audit-checklist.md) — confirm required evidence and deliverables before handoff.

Use the checklists as review aids; mark an item complete only when its supporting artifact exists.
