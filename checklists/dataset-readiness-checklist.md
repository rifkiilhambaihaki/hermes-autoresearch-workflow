# Dataset Readiness Checklist

- [ ] Sumber dataset, lisensi/izin penggunaan, dan batas redistribusi tercatat.
- [ ] Privasi, consent, dan data-subject grouping diperiksa bila relevan.
- [ ] Struktur folder kelas benar.
- [ ] Jumlah kelas benar.
- [ ] Nama kelas sesuai kebutuhan.
- [ ] Jumlah data per kelas dihitung.
- [ ] Total data dihitung.
- [ ] Format file dicek.
- [ ] Resolusi/ukuran gambar dicek.
- [ ] Mode warna dicek.
- [ ] Tidak ada file corrupt, atau daftar file corrupt tersedia.
- [ ] Tidak ada file non-gambar, atau daftar file non-gambar tersedia.
- [ ] Duplikasi nama file dicek.
- [ ] Kemungkinan duplikasi gambar dicek.
- [ ] Potensi data leakage dicek.
- [ ] Split strategy ditentukan.
- [ ] Rekomendasi preprocessing ditulis.
